# PharmaGo 
EC5207 - DevOps Engineering module project:
PharmaGo is a web-based platform that allows customers to browse medicines, upload prescriptions, and order home delivery from a pharmacy. Pharmacists manage inventory, verify prescriptions, and process orders through an admin dashboard. Customers can track their order status in real time from confirmation to delivery. The system streamlines pharmacy operations while making the medicine ordering process simple and convenient for customers.
